Politique de confidentialité — Agentic OS Enzo

Dernière mise à jour : 29 septembre 2026

1. Qui utilise l'application

Agentic OS Enzo est un outil personnel utilisé par un seul utilisateur : le propriétaire du compte TikTok @enzo.dkd. Il ne collecte aucune donnée sur d'autres personnes.

2. Données utilisées

Avec l'autorisation du propriétaire, via l'API officielle de TikTok :

  • informations de base du compte (identifiant, nom affiché, photo de profil) — pour afficher le compte connecté ;
  • jeton d'accès — pour téléverser et publier les vidéos à la demande du propriétaire.

3. Stockage

Ces données sont conservées uniquement sur l'ordinateur du propriétaire, dans un coffre chiffré. Elles ne sont envoyées à aucun serveur tiers, ni vendues, ni partagées.

4. Durée

Les données sont conservées tant que le compte est connecté. La révocation de l'accès (paramètres TikTok → Sécurité → Applications autorisées) ou la déconnexion dans l'application supprime le jeton.

5. Vos droits

Le propriétaire peut à tout moment consulter, supprimer ou révoquer ces données.
